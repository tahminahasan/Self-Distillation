## Dataset

**BreakHis: Breast Cancer Histopathological Image Dataset**

- **Original publication:** [A Dataset for Breast Cancer Histopathological Image Classification](https://doi.org/10.1109/TBME.2015.2496264)
- **Dataset download:** [BreakHis Dataset on Kaggle](https://www.kaggle.com/datasets/waseemalastal/breakhis-breast-cancer-histopathological-dataset)
- **Classes:** Benign and malignant
- **Magnifications:** 40×, 100×, 200×, and 400×
